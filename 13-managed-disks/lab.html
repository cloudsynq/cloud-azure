Azure Managed Disk (Block Storage)
Lab performed: October 8, 2026  ·  VM: simpleLinuxVM (Ubuntu 22.04)  ·  Disk: 1 TB Standard SSD

1. What is Azure Managed Disk?

💾
Simple Analogy Sochो Azure Managed Disk ek external hard drive hai jo tum apni VM (computer) se attach aur detach kar sakte ho. Jaise pendrive ek computer se nikaalke doosre mein lagaate ho — waisa hi.
Definition

Managed Disk ek block storage service hai — VM ke saath directly attach hoti hai aur OS jaisi koi bhi disk lagti hai. Azure khud disk ka management karta hai (replication, backups, encryption).

Storage TypeAzure ServiceUse Case
Block Storage This LabManaged DisksVM ka OS disk, database disk
Object StorageBlob StorageFiles, images, backups (previous labs)
File StorageAzure FilesShared network drive (Lab 4-5)

4. Lab Steps — What We Did

1
Managed Disk Create kiya (Portal) Portal → Disks → + Create → 1TB Standard SSD, Resource Group: Storage-RG
2
Disk VM se Attach kiya VM → Disks → + Attach existing disk → disk select karo → Save
3
Disk Format kiya (ext4) sudo mkfs.ext4 /dev/nvme0n2 — Disk ke andar filesystem banaya
4
Disk Mount kiya sudo mkdir /mnt/mydata then sudo mount /dev/nvme0n2 /mnt/mydata
5
Ownership fix kiya sudo chown sahil:sahil /mnt/mydata — Permission denied fix
6
Persistent Mount (fstab) echo '/dev/nvme0n2 /mnt/mydata ext4 defaults 0 0' | sudo tee -a /etc/fstab
7
OS Disk Snapshot liya Portal → VM → Disks → OS Disk → Create Snapshot → Full snapshot
8
Snapshot se Recovery process samjhi Snapshot → Create Disk → VM stop → Swap OS Disk → VM start = Recovery complete

5. Key Commands — Exam ke liye Yaad Rakho

Disk dekho

lsblk # sari disks aur mount points dikhao df -h # mounted disks aur space dikhao

Format karo

sudo mkfs.ext4 /dev/nvme0n2 # disk ko ext4 filesystem se format karo

Mount karo

sudo mkdir /mnt/mydata # mount point folder banao sudo mount /dev/nvme0n2 /mnt/mydata # disk ko folder se jodo

Persistent mount (reboot ke baad bhi kaam kare)

echo '/dev/nvme0n2 /mnt/mydata ext4 defaults 0 0' | sudo tee -a /etc/fstab cat /etc/fstab # verify entry

Permission fix

sudo chown sahil:sahil /mnt/mydata # folder ka owner apna user banao

6. Important Concepts

mkfs vs mount — Difference

CommandKya karta haiAnalogy
mkfs.ext4Disk ko format karta hai, filesystem banata haiNayi notebook mein lines/pages banana
mountDisk ko ek folder se attach karta haiNotebook ko shelf pe rakhna jahan se use kar sako
/etc/fstabAutomatic mount on bootNotebook hamesha wahi shelf pe auto-place

Snapshot vs Backup

SnapshotBackup
SpeedInstant (seconds)Slow (minutes/hours)
StorageIncremental — sirf changesFull copy
UseQuick rollback before changesLong-term data retention
Azure ServiceDisk SnapshotAzure Backup
Recovery Flow

Snapshot → Create Disk → Stop VM → Swap OS Disk → Start VM
Agar OS corrupt ho jaaye — yeh steps follow karo aur VM wapas usi state mein aa jaayegi.
